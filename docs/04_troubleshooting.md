# คู่มือแก้ปัญหาที่พบบ่อย (Troubleshooting)

รวบรวมปัญหาและวิธีแก้ไขที่พบบ่อยระหว่างการติดตั้งและทดสอบระบบ

---

## ปัญหาฝั่งบอร์ด Cucumber (PlatformIO / Hardware)

### 1. คอมไพล์ไม่ผ่าน ขึ้น Error `'Serial' was not declared in this scope`
* **สาเหตุ:** ตั้งค่า `ARDUINO_USB_MODE=1` ซึ่งไม่ตรงกับสถาปัตยกรรมของชิป ESP32-S2
* **วิธีแก้:** ตรวจสอบไฟล์ `platformio.ini` ให้ตั้งค่าแฟล็กดังนี้:
  ```ini
  build_flags = 
      -D ARDUINO_USB_CDC_ON_BOOT=0
      -D ARDUINO_USB_MODE=0
  ```

### 2. อัปโหลดโค้ดไม่ได้ ขึ้น `PermissionError(13, 'Access is denied.')`
* **สาเหตุ:** หน้าต่าง Serial Monitor เปิดค้างอยู่ ทำให้แย่งพอร์ต COM กับตัวอัปโหลด
* **วิธีแก้:** กดรูป **ถังขยะ (Kill Terminal)** ที่แถบ Serial Monitor ด้านล่างก่อนกด Upload ทุกครั้ง หากยังไม่ได้ให้ถอดสาย USB แล้วเสียบใหม่

### 3. อัปโหลดเสร็จขึ้น `entry 0x4004c18c` แล้วหน้าจอเงียบ ไม่มีข้อความวิ่งต่อ
* **สาเหตุ:** บอร์ด Cucumber มีพอร์ต USB-C 2 ช่อง (ช่อง **UART** และช่อง **USB OTG**) หากตั้ง `ARDUINO_USB_CDC_ON_BOOT=1` ข้อความจะถูกส่งไปออกที่ช่อง USB OTG แทน
* **วิธีแก้:** ตั้งค่า `-D ARDUINO_USB_CDC_ON_BOOT=0` ใน `platformio.ini` แล้วอัปโหลดใหม่ ข้อความจะแสดงออกทางช่อง UART ทันที

### 4. บอร์ดไม่เชื่อมต่อ Wi-Fi
* **สาเหตุ:** บอร์ด ESP32-S2 รองรับเฉพาะคลื่น **2.4 GHz** หากชื่อ Wi-Fi เป็นคลื่น 5 GHz บอร์ดจะมองไม่เห็น

## ปัญหาฝั่ง Google Colab และ Telegram Bot

### 1. ติดตั้ง Ollama ไม่ผ่าน ขึ้น Error `This version requires zstd for extraction`
* **สาเหตุ:** เครื่องเสมือนของ Google Colab ไม่มีโปรแกรมแตกไฟล์ `zstd` ติดตั้งมาให้
* **วิธีแก้:** เพิ่มบรรทัด `!apt-get update -qq && apt-get install -y -qq zstd` ไว้บนสุดของ Cell ที่ 1 ก่อนรันสคริปต์ติดตั้ง Ollama

### 2. พิมพ์แชตใน Telegram แล้วบอทตอบช้ามาก (เกิน 30 วินาที)
* **สาเหตุ:** ยังไม่ได้เปลี่ยน Runtime ของ Google Colab เป็น GPU (กำลังรัน AI ด้วย CPU) หรือเป็นการถามคำถามแรกที่โมเดลกำลังโหลดเข้าหน่วยความจำ
* **วิธีแก้:** ไปที่ **Runtime > Change runtime type** เลือกเป็น **T4 GPU**

### 3. บอทตอบว่า *"ยังไม่ได้รับข้อมูลจากบอร์ด"* (`null`)
* **สาเหตุ:** ค่า `BOARD_ID` ใน Google Colab กับในโค้ดบอร์ด Cucumber ไม่ตรงกัน หรือบอร์ดยังไม่ได้เสียบไฟเชื่อมต่ออินเทอร์เน็ต
* **วิธีแก้:** ตรวจสอบตัวสะกดของ `BOARD_ID` ทั้งสองฝั่งให้ตรงกันทุกตัวอักษร
