# บทที่ 1: เตรียมบอร์ด Cucumber และอัปโหลดโค้ด

ในบทนี้เราจะทำความรู้จักอุปกรณ์ที่ฝังอยู่บนบอร์ด **Cucumber (ESP32-S2)** และอัปโหลดโค้ดเพื่อให้อ่านค่าสภาพแวดล้อมในห้องส่งขึ้นอินเทอร์เน็ต

---

## 1. รู้จักอุปกรณ์บนบอร์ด Cucumber
บอร์ด Cucumber มีเซนเซอร์และหลอดไฟติดตั้งมาให้พร้อมใช้งานบนบอร์ดแล้ว โดยไม่ต้องต่อสายไฟเพิ่ม:

| อุปกรณ์ | ชื่อชิป / ขาเชื่อมต่อ | หน้าที่ในโปรเจกต์ |
| :--- | :--- | :--- |
| **เซนเซอร์อุณหภูมิและความชื้น** | `HTS221` (I2C: SDA=41, SCL=40) | วัดอุณหภูมิ (°C) และความชื้นสัมพัทธ์ (%) |
| **เซนเซอร์ความดันอากาศ** | `BMP280` (I2C Address `0x76`) | วัดความดันบรรยากาศ (hPa) |
| **หลอดไฟแสดงสถานะ** | `NeoPixel RGB LED` (GPIO 18) | แสดงสีตามอุณหภูมิ (Auto) หรือตามคำสั่งแชต (Manual) |

---

## 2. เตรียมเครื่องมือและดาวน์โหลดโค้ด
1. ติดตั้งโปรแกรม **VS Code** และส่วนขยาย **PlatformIO IDE**
2. ดาวน์โหลดโค้ดของโปรเจกต์จาก GitHub (กดปุ่มสีเขียว **Code > Download ZIP** แล้วแตกไฟล์)
3. เปิดโฟลเดอร์ `firmware/` ด้วยโปรแกรม VS Code

---

## 3. ตั้งค่า Wi-Fi และรหัสบอร์ด (`BOARD_ID`)
เปิดไฟล์ `firmware/src/main.cpp` แล้วแก้ไขข้อมูล 3 บรรทัดด้านบนสุด:

```cpp
const char* WIFI_SSID = "ชื่อ_WIFI_2.4GHz_ของคุณ";
const char* WIFI_PASS = "รหัสผ่าน_WIFI";

// ตั้งชื่อเฉพาะตัว ห้ามซ้ำกับเพื่อนในห้องเรียน!
const char* BOARD_ID  = "cucumber-room-01"; 
```

> **ข้อควรระวัง:** บอร์ด ESP32-S2 รองรับเฉพาะ **Wi-Fi คลื่น 2.4 GHz** เท่านั้น (ไม่รองรับ 5 GHz) และหากใช้ Hotspot มือถือ ให้เปิดโหมด *Maximize Compatibility*

---

## 4. อัปโหลดโค้ดและดูผลลัพธ์ (115200 baud)
1. เสียบสาย USB-C เข้าที่ช่อง **UART** ของบอร์ด Cucumber
2. กดปุ่ม **PlatformIO: Upload** (รูปหัวลูกศรชี้ขวา `->` ที่แถบด้านล่างของ VS Code)
3. เมื่ออัปโหลดเสร็จ 100% ให้กดปุ่ม **PlatformIO: Serial Monitor** (รูปปลั๊กไฟ) ตรวจสอบความเร็วที่ **115200 baud**

### ตัวอย่างผลลัพธ์ที่ถูกต้อง
```text
=== Cucumber AIoT Booting (115200 baud) ===
[Init] NeoPixel RGB LED OK
[Init] HTS221 Sensor OK
[Init] BMP280 Sensor OK
[WiFi] Connected! IP: 192.168.1.xxx
[MQTT] Connected!
[MQTT] Subscribed: cucumber-aiot/cucumber-room-01/command
[Telemetry] {"temp":27.4,"humidity":62.5,"pressure":1009.8,"mode":"AUTO","led":"GREEN"}
```

สังเกตที่ตัวบอร์ด: ไฟ RGB LED จะสว่างเป็น **สีเขียว** (หากอุณหภูมิไม่เกิน 28°C) หรือ **สีแดง** (หากอุณหภูมิสูงเกิน 28°C)
