# Cucumber AIoT for Beginners

เรียนรู้การสร้าง **ผู้ช่วยดูแลสภาพแวดล้อมในห้องอัจฉริยะ (Smart Room Assistant)** ด้วยบอร์ด Cucumber (ESP32-S2), AI บน Google Colab และสั่งงานผ่านแชต Telegram

## ภาพรวมระบบ
* **บอร์ด IoT:** อ่านค่าอุณหภูมิและความชื้นจากเซนเซอร์บนบอร์ด Cucumber และแสดงสถานะผ่านไฟ RGB LED
* **การสื่อสาร:** รับ-ส่งข้อมูลแบบ Real-time ผ่าน MQTT Broker
* **สมองกล AI:** แปลงข้อความภาษาไทยเป็นคำสั่งควบคุมอุปกรณ์ด้วยโมเดล Gemma บน Google Colab
* **ส่วนติดต่อผู้ใช้:** ถาม-ตอบและสั่งงานผ่าน Telegram Bot

---

## บทเรียนสำหรับผู้เรียน (Students)
1. เตรียมเครื่องมือและรู้จักบอร์ด Cucumber
2. อ่านค่าเซนเซอร์และควบคุมไฟ RGB LED
3. เชื่อมต่อ Wi-Fi และส่งข้อมูลผ่าน MQTT
4. ทดลองสั่งงานบอร์ดผ่านแชต Telegram

## คู่มือสำหรับผู้สอน (Instructors)
1. การตั้งค่า Telegram Bot Token
2. การเปิดใช้งาน AI และระบบตัวกลางบน Google Colab
