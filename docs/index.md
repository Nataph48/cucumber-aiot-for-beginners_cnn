# Cucumber AIoT for Beginners

เรียนรู้การสร้าง **ผู้ช่วยดูแลสภาพแวดล้อมในห้องอัจฉริยะ (Smart Room Assistant)** ด้วยบอร์ด **Cucumber (ESP32-S2)** ประมวลผลภาษาธรรมชาติด้วย **AI (Gemma)** บน Google Colab และสั่งงานผ่านแชต **Telegram**

---

## ภาพรวมการทำงานของระบบ (Architecture)

ระบบแบ่งการทำงานออกเป็น 3 ส่วนที่สื่อสารกันผ่านอินเทอร์เน็ตแบบ Real-time:

```text
+-----------------------------------+         +-----------------------+
|   บอร์ด Cucumber (ESP32-S2)        |         |     MQTT Broker       |
|  - อ่านค่า Temp / Humidity / Press | ------> |  (broker.emqx.io)     |
|  - ควบคุมไฟ RGB LED (Auto/Manual) | <------ |  รับ-ส่งข้อมูล JSON     |
+-----------------------------------+         +-----------------------+
                                                         ^  |
                                           ส่งคำสั่ง JSON  |  | ส่งค่าเซนเซอร์
                                                         |  v
+-----------------------------------+         +-----------------------+
|          ผู้เรียน (Telegram)        | <-----> |  Google Colab (ผู้สอน) |
|  พิมพ์แชตภาษาไทยถาม-ตอบและสั่งเปิดไฟ   |         |  AI (Gemma 2) + Bot   |
+-----------------------------------+         +-----------------------+
```

### หลักการออกแบบ AIoT ที่ปลอดภัย (AI + Rule-Based Control)
* **AI ทำหน้าที่แปลภาษา:** โมเดล Gemma แปลงประโยคภาษาไทยทั่วไป (เช่น *"ตอนนี้ในห้องร้อนไหม"* หรือ *"เปิดไฟสีฟ้าหน่อย"*) ให้กลายเป็นคำสั่งมาตรฐาน (`GET_STATUS`, `LED_BLUE`)
* **บอร์ดทำหน้าที่ควบคุมตามกฎ:** ในโหมดอัตโนมัติ (`AUTO`) บอร์ดจะใช้กฎที่ตรวจสอบได้ (ถ้าอุณหภูมิ > 28°C ไฟเป็นสีแดง, ถ้าปกติเป็นสีเขียว) โดยไม่ให้ AI เข้าไปแก้ไขโค้ดฮาร์ดแวร์โดยตรง
